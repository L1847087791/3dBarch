# 12.30 迭代说明

## 一、新增功能：唯一标识 UUID

为外层（bar）和内层（layer）添加 `uuid` 字段，用于交互时向后端 POST 请求携带。

### 1.1 改动文件

| 文件 | 改动 |
|------|------|
| `BarChart3D.jsx` | mock 数据中生成 uuid（使用 `uuid` 库） |
| `BarManager.js` | `BarManager` 构造函数新增 `uuid` 参数；`innerLayers` 数据增加 `uuid` 字段 |
| `InteractionManager.js` | 点击事件打印对象中增加 `uuid` / `barUuid` / `layerUuid` |

### 1.2 设计说明

- uuid 由数据源（mock / 后端）提供，内部类只负责存储和透传
- 不在内部类中兜底生成，保持职责单一

---

## 二、当前数据接口格式

```javascript
const sceneData = {
  bars: [
    {
      position: { x: 0, y: 0, z: 0 },
      groupName: '数据集 A',
      height: 40,                    // 外层目标高度
      outerColor: 'normal',          // 外层颜色标识
      uuid: 'bar-uuid-001',          // 外层唯一标识
      layers: [
        { color: 'normal', uuid: 'layer-uuid-001' },
        { color: 'warning', uuid: 'layer-uuid-002' },
        // ...
      ]
    }
  ]
};
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `position` | Object | 是 | 柱状图位置 `{x, y, z}` |
| `groupName` | string | 否 | 所属分组名称 |
| `height` | number | 是 | 外层目标高度 |
| `outerColor` | string | 否 | 外层颜色标识，默认 `'normal'` |
| `uuid` | string | 是 | 外层唯一标识（用于交互传参） |
| `layers[].color` | string | 否 | 内层颜色标识，默认 `'normal'` |
| `layers[].uuid` | string | 是 | 内层唯一标识（用于交互传参） |
