# 12.30 迭代说明

## 一、新增功能：唯一标识 UUID

为外层（bar）和内层（layer）添加 `uuid` 字段，用于交互时向后端 POST 请求携带。

### 1.1 改动文件

| 文件 | 改动 |
|------|------|
| `BarChart3D.jsx` | mock 数据中生成 uuid（使用 `uuid` 库） |
| `BarManager.js` | `BarManager` 构造函数新增 `uuid` 参数；`innerLayers` 数据增加 `uuid` 字段 |
| `InteractionManager.js` | 点击事件打印对象中增加 `uuid` / `barUuid` / `layerUuid` |

### 1.2 设计说明

- uuid 由数据源（mock / 后端）提供，内部类只负责存储和透传
- 不在内部类中兜底生成，保持职责单一

## 二、当前数据接口格式

```javascript
const sceneData = {
  bars: [
    {
      position: { x: 0, y: 0, z: 0 },
      groupName: '数据集 A',
      height: 40,                    // 外层目标高度
      outerColor: 'normal',          // 外层颜色标识
      uuid: 'bar-uuid-001',          // 外层唯一标识
      layers: [
        { color: 'normal', uuid: 'layer-uuid-001' },
        { color: 'warning', uuid: 'layer-uuid-002' },
        // ...
      ]
    }
  ]
};
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `position` | Object | 是 | 柱状图位置 `{x, y, z}` |
| `groupName` | string | 否 | 所属分组名称 |
| `height` | number | 是 | 外层目标高度 |
| `outerColor` | string | 否 | 外层颜色标识，默认 `'normal'` |
| `uuid` | string | 是 | 外层唯一标识（用于交互传参） |
| `layers[].color` | string | 否 | 内层颜色标识，默认 `'normal'` |
| `layers[].uuid` | string | 是 | 内层唯一标识（用于交互传参） |

## 三、新增功能：GSAP 动画集成

为柱状图高度变化引入 GSAP 动画库，实现丝滑的升起过渡效果。

### 3.1 新增文件

**`src/utils/BarAnimationManager.js`** - 独立的动画管理器

| 方法 | 说明 |
|------|------|
| `animateHeights(barsData, options)` | 动画化所有柱状图高度 |
| `animateBarHeight(barIndex, targetHeight, options)` | 动画化单个柱状图 |
| `killAll()` / `killBar(barIndex)` | 停止动画 |
| `dispose()` | 销毁管理器 |

### 3.2 改动文件

| 文件 | 改动 |
|------|------|
| `BarManager.js` | 导入动画管理器；构造函数新增 `animationManager`；`_initializeHeights` 改用动画；新增 `animateAllHeights` |
| `package.json` | 新增 `gsap` 依赖 |

### 3.3 动画配置

```javascript
{
  duration: 0.8,       // 动画时长（秒）
  ease: 'power2.out',  // 缓动函数（升起后自然减速）
  onComplete: null     // 完成回调
}
```

### 3.4 使用方式

```javascript
// 初始化时自动触发动画
barCollectionManager.createBars(sceneData, 8, 5);

// 动态更新（带动画）
barCollectionManager.animateAllHeights([50, 45, ...], { duration: 0.6 });

// 立即更新（无动画）
barCollectionManager.updateAllHeights([50, 45, ...]);
```
