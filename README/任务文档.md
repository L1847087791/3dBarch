## 任务需求

1. 当前只具备场景初始化的功能，即后端传入数据快照，前端生成该快照的场景
2. 需求1：需要加入控制面板，控制面板中有多种功能，最主要功能是可以输入关键字过滤或搜索相应柱状图数据并作为快照生成
3. 需求2：需要考虑并丰富柱状图交互细节，基础功能是悬停外层和内层时在其旁面显示浮层、点击内层或外层时弹出状态弹窗。

## 落地想法

1. 对于需求一：考虑在BarChart3D组件上加一个父组件，这用于接收和控制初始化数据并传入至BarChart3D。最终效果是初始进入时有一个初始快照（后端返回），后续控制面板进行过滤或搜索操作后后端再次返回相应快照。这样父组件每次获得快照后都会根据后端返回的数据重新生成柱状图，这里是否涉及到场景的销毁和重建？目前性能如何？是否有别的更好方案
2. 对于需求二：目前已经实现了鼠标拾取功能，只需要在相应事件中加入弹窗和浮层即可。但是需要考虑弹窗和浮层怎么在three.js场景中生成，目前两个想法：方法一是在canvas节点外建立其他dom节点，这样可以完美使用antd组件库和自定义样式（无缝衔接传统web应用），然后利用react组件的状态控制显示弹窗或浮层的显示（隐藏）。对于弹窗则很好显示，因为只需要显示在固定位置即可，但是对于浮层则需要显示在相应柱状图旁边（需要定位柱状图坐标，考虑怎么定位？）。方法二是使用three.js中提供的精灵图进行二维显示，好处是可以直接定位浮层和弹窗具体位置，适配three.js场景。坏处是代码复杂度高、无法直接使用antd组件库。
3. 由于是3D场景，柱状图之间会被互相遮挡，考虑点击某一柱状图时做一些特殊处理，主要是防止其他柱状图遮挡该柱状图，可以虚化其他柱状图（或周围柱状图），使得该柱状图不被遮挡。后期可添加动态体验，比如摄像机移动到该柱状图附近并看向该柱状图（可利用gsap动画实现）
