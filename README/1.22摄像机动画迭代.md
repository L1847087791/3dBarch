## 任务需求

1. 分析当前交互细节
2. 完善交互流程中的点击主机事件
3. 按照任务步骤要求严格进行

## 任务步骤

1. 快速查看src\utils\InteractionManager.js及其相关文件，这是交互管理器的主要文件，涉及到鼠标移动和鼠标点击的一些交互功能
2. 目前需要在原有的基础上增加控制摄像机的功能，具体要求如下:
3. 点击主机（外层）时摄像机聚焦到该主机位置，并且移动到主机附近。这个过程可以利用gsap动画过渡实现
4. 第一段移动摄像头动画结束后需要隐藏屏幕中的现有css2d的区域标签，同时在该主机的每个内层旁边显示css2d文字标签，文字内容为该层的组件名称，即组件中存储的component.mc。要求该标签不同于区域标签，背景透明，只需显色白色文字即可，高度和内层高度一致  
5. 之后的交互不需要额外修改，保持原有交互，比如点击空白区域或其他柱状图外层恢复虚化效果，摄像机状态不需要改变  
6. 当虚化效果消失再次点击其他柱状图则会重复流程1，注意销毁当前柱状图的css2d文字  
7. 新添加摄像机重置按钮，UI为小圆形按钮，点击后摄像机保持当前位置，但是需要聚焦到初始位置，此时区域标签显示，内层文字销毁。

## 注意事项

1. 移动摄像头可以全程使用gsap实现，保证交互丝滑度，点击主机后摄像机的落点并不需要随机，可以拿到主机的位置坐标，此时摄像机落点就是(x+offx,y,z+offy)。即x和z是在主机位置上添加固定偏移即可，y需要调整到可看到该主机全景的位置。注意此位置不能被其他主机所遮挡
2. 当摄像机移动后，内层文字的显示可以利用gsap自上而下显示出来
3. 代码做到解耦，此功能不应糅合在交互管理类中，可以新建文件或放入摄像机控制类中，总之你需要保证代码的可读性和可维护性
