## 任务需求

1. 整理并重新定义颜色映射
2. 按照新的数据返回格式来模拟数据
3. 依据新的返回数据字段来展示浮层

## 任务步骤

1. 先分析当前项目中用到的颜色映射，比如src\utils\BarManager.js中的内层颜色和外层颜色、src\utils\ViewModeManager.js的指标颜色。不再需要外层的颜色映射，外层始终固定为normal（数据接口不再需要传入），内层颜色总共分为4个等级，0（正常，#EDF2FA）1（次要#ffcd3d）2（主要#ff8c3d）3（严重#d9001b）。指标颜色没有告警区分，只有指标之间的区分颜色，默认为当前的五个颜色即可，但是需要更改颜色映射名称（不再是告警等级含义）
2. 分析数据返回格式，按照数据返回格式的组件视图以及指标视图来定义mock生成数据。这属于高度模拟联调阶段，由于后端数据没有返回位置数组，因此你需要创建一个位置生成算法（参照src\components\BarChartContainer.jsx模拟5000数据），这个算法按照后端返回的主机和分组来创建对应的位置。然后创建一个转化函数，这个函数需要将后端数据转化为前端直接可用的数据格式。
3. 按层级（主机、服务组件、指标）保存返回的其他的相关的数据，以便后续迭代时使用数据
4. 开始迭代浮层展示优化，组件视图下浮层展示内容为：标题为主机名称：主机ip，内容每一行为服务组件类型数量*服务组件类型；指标视图下浮层展示内容为:标题为主机名称:主机ip，每一行内容为指标名称：指标的value百分比值，每个指标文字是不同颜色（文字颜色对应指标的颜色）
