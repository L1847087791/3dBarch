# 3D 柱状图性能重构优化文档

## 一、项目背景与问题描述

### 1.1 项目概述

本项目是一个基于 Three.js 的 3D 柱状图可视化应用，使用 React 框架构建。场景中包含：

- **160 个柱状图**（分为 3 个数据集：A、B、C）
- **每个柱状图 50 个内层**（用于展示分层数据）
- **交互功能**：悬停缩放、点击选中、内层闪烁高亮、选中光标动画

### 1.2 性能问题

优化前的性能表现：

| 指标 | 数值 |
|------|------|
| 首屏加载时间 | 7-9 秒 |
| 帧率 | < 20 FPS |
| Draw Calls | ~16,160 次 |
| Mesh 对象数量 | ~16,160 个 |

### 1.3 问题分析

原始实现中，每个柱状图的每个层级都创建独立的 Mesh 对象：

```
160 个柱状图 × (1 外壳 + 50 内层 + 50 边框) = 16,160 个独立对象
```

这导致：
1. **过多的 Draw Calls**：每个 Mesh 都需要单独的绘制调用
2. **重复的 Geometry 创建**：相同尺寸的几何体被重复创建
3. **Material 状态切换开销**：每个 Mesh 可能触发 GPU 材质状态切换
4. **内存占用过高**：大量重复对象占用内存

---

## 二、优化策略概述

基于 Three.js 性能优化最佳实践，制定了 4 步渐进式优化方案：

| 步骤 | 优化内容 | 预期效果 |
|------|----------|----------|
| Step 1 | 全局共享 Material | 减少材质切换开销 |
| Step 2 | 全局共享 Geometry（缓存） | 减少内存占用 |
| Step 3 | InstancedMesh 替换内层 | 大幅减少 Draw Calls |
| Step 4 | InstancedMesh 外壳 + 合并边框 | 进一步减少 Draw Calls |

---

## 三、Step 1：全局共享 Material

### 3.1 优化原理

Three.js 在渲染时，如果相邻 Mesh 使用不同的 Material，GPU 需要进行材质状态切换，这是一个昂贵的操作。通过让所有相同类型的 Mesh 共享同一个 Material 实例，可以避免这种开销。

### 3.2 实现方式

在 `BarManager.js` 中创建全局共享材质对象：

```javascript
/**
 * 全局共享材质（性能优化：避免材质切换开销）
 */
const SharedMaterials = {
  // 外壳材质（透明）
  outerShell: new THREE.MeshBasicMaterial({
    color: '#EDF2FA',
    transparent: true,
    opacity: 0.2,
  }),
  // 内层材质（Phong光照）
  innerLayer: new THREE.MeshPhongMaterial({
    color: '#EDF2FA',
    emissive: 0xaaaaaa,
    emissiveIntensity: 0.3,
    shininess: 50
  }),
  // 边框材质
  edges: new THREE.LineBasicMaterial({
    color: 0xffffff,
    linewidth: 1
  })
};
```

### 3.3 注意事项

**问题**：共享材质后，修改一个 Mesh 的材质属性会影响所有使用该材质的 Mesh。

**解决方案**：在需要单独修改材质的场景（如内层闪烁高亮），临时克隆材质：

```javascript
// 闪烁时克隆材质
const clonedMaterial = SharedMaterials.innerLayer.clone();
mesh.material = clonedMaterial;

// 闪烁结束后恢复共享材质
mesh.material.dispose();
mesh.material = SharedMaterials.innerLayer;
```

## 四、Step 2：全局共享 Geometry（几何体缓存）

### 4.1 优化原理

相同尺寸的柱状图使用完全相同的几何形状，无需重复创建。通过缓存机制，相同参数的几何体只创建一次。

### 4.2 实现方式

创建几何体缓存管理器：

```javascript
/**
 * 几何体缓存管理器
 * 使用 key 缓存不同尺寸的几何体
 */
const GeometryCache = {
  outerShellCache: new Map(),
  innerLayerCache: new Map(),
  edgesCache: new Map(),

  /**
   * 获取或创建外壳几何体
   */
  getOuterShellGeometry(width, height) {
    const key = `${width}_${height}`;
    if (!this.outerShellCache.has(key)) {
      this.outerShellCache.set(key, new THREE.BoxGeometry(width, height, width));
    }
    return this.outerShellCache.get(key);
  },

  /**
   * 获取或创建内层几何体
   */
  getInnerLayerGeometry(width, height) {
    const key = `${width}_${height}`;
    if (!this.innerLayerCache.has(key)) {
      this.innerLayerCache.set(key, new THREE.BoxGeometry(width, height, width));
    }
    return this.innerLayerCache.get(key);
  },

  /**
   * 获取或创建边框几何体
   */
  getEdgesGeometry(width, height) {
    const key = `${width}_${height}`;
    if (!this.edgesCache.has(key)) {
      const boxGeom = this.getInnerLayerGeometry(width, height);
      this.edgesCache.set(key, new THREE.EdgesGeometry(boxGeom));
    }
    return this.edgesCache.get(key);
  },

  /**
   * 清理所有缓存的几何体
   */
  dispose() {
    this.outerShellCache.forEach(geom => geom.dispose());
    this.outerShellCache.clear();
    // ... 其他缓存清理
  }
};
```

### 4.3 效果

- 内存占用显著降低
- 减少 GC（垃圾回收）压力
- 首屏加载时间缩短至 2 秒内

## 五、Step 3：InstancedMesh 替换内层 Mesh

### 5.1 优化原理

`THREE.InstancedMesh` 是 Three.js 提供的批量渲染方案，允许使用单个 Draw Call 渲染多个相同几何体的实例，每个实例可以有不同的变换矩阵（位置、旋转、缩放）。

```
优化前：8000 个内层 Mesh = 8000 次 Draw Call
优化后：1 个 InstancedMesh = 1 次 Draw Call
```

### 5.2 架构调整

**BarManager 类简化为纯数据管理：**

```javascript
class BarManager {
  constructor(...) {
    // 不再创建 Mesh，只管理数据
    this.innerLayers = [];        // 层数据
    this.layerInstanceIds = [];   // 每层在 InstancedMesh 中的 ID
  }

  // 只计算数据，不操作 Mesh
  updateHeight(layerValues) {
    // 计算每层的 scaleY 和 positionY
    // 返回更新后的层数据
  }
}
```

**BarCollectionManager 统一管理 InstancedMesh：**

```javascript
class BarCollectionManager {
  constructor(scene) {
    this.innerLayerInstancedMesh = null;   // 内层 InstancedMesh
    this.instanceIdToLayer = new Map();    // instanceId -> {barIndex, layerIndex}
  }

  _createInnerLayerInstancedMesh() {
    const layerGeometry = GeometryCache.getInnerLayerGeometry(innerWidth, layerBaseHeight);

    this.innerLayerInstancedMesh = new THREE.InstancedMesh(
      layerGeometry,
      SharedMaterials.innerLayer,
      this.totalLayerCount  // 8000
    );

    this.scene.add(this.innerLayerInstancedMesh);
  }

  // 更新单个实例的变换矩阵
  _updateInstanceMatrix(instanceId, barPosition, layerData) {
    this.tempPosition.set(barPosition.x, layerData.positionY, barPosition.z);
    this.tempScale.set(1, layerData.scaleY, 1);
    this.tempMatrix.compose(this.tempPosition, this.tempQuaternion, this.tempScale);
    this.innerLayerInstancedMesh.setMatrixAt(instanceId, this.tempMatrix);
  }
}
```

### 5.3 交互适配

InstancedMesh 的射线检测返回 `instanceId`，需要建立映射关系：

```javascript
// 创建时建立映射
this.instanceIdToLayer.set(instanceId, { barIndex: index, layerIndex: i });

// 射线检测时使用
const intersects = this.raycaster.intersectObject(instancedMesh);
if (intersects.length > 0) {
  const instanceId = intersects[0].instanceId;
  const layerInfo = this.instanceIdToLayer.get(instanceId);
  // layerInfo = { barIndex, layerIndex }
}
```

### 5.4 关键配置

```javascript
// 禁用视锥剔除（确保所有实例都参与射线检测）
this.innerLayerInstancedMesh.frustumCulled = false;

// 更新矩阵后重新计算包围球（射线检测需要）
this.innerLayerInstancedMesh.computeBoundingSphere();
```

## 六、Step 4：InstancedMesh 外壳 + 合并边框

### 6.1 外壳 InstancedMesh

与内层相同的方式处理外壳：

```javascript
_createOuterShellInstancedMesh(count) {
  const shellGeometry = GeometryCache.getOuterShellGeometry(this.barWidth, this.maxHeight);

  this.outerShellInstancedMesh = new THREE.InstancedMesh(
    shellGeometry,
    SharedMaterials.outerShell,
    count  // 160
  );

  // 设置每个外壳的变换矩阵
  this.bars.forEach((bar, index) => {
    this.tempPosition.set(bar.position.x, bar.position.y + this.maxHeight / 2, bar.position.z);
    this.tempMatrix.compose(this.tempPosition, this.tempQuaternion, this.tempScale);
    this.outerShellInstancedMesh.setMatrixAt(index, this.tempMatrix);

    // 创建代理对象用于交互识别
    bar.outerShell = {
      userData: { barIndex: index, raycastEnabled: true },
      scale: { x: 1, z: 1 }
    };
  });
}
```

### 6.2 合并边框几何体

边框使用 `LineSegments`，无法直接使用 InstancedMesh。采用几何体合并方案：

```javascript
import { mergeGeometries } from 'three/examples/jsm/utils/BufferGeometryUtils.js';

_createMergedEdges() {
  const edgesGeometry = GeometryCache.getEdgesGeometry(innerWidth, layerBaseHeight);
  const edgesGeometries = [];

  // 收集所有边框几何体（变换后）
  this.bars.forEach(bar => {
    bar.innerLayers.forEach((layerData) => {
      const clonedGeom = edgesGeometry.clone();
      const matrix = new THREE.Matrix4();
      matrix.makeTranslation(bar.position.x, layerData.positionY, bar.position.z);

      const scaleMatrix = new THREE.Matrix4();
      scaleMatrix.makeScale(1, layerData.scaleY, 1);
      matrix.multiply(scaleMatrix);

      clonedGeom.applyMatrix4(matrix);
      edgesGeometries.push(clonedGeom);
    });
  });

  // 合并为单个几何体
  const mergedGeometry = mergeGeometries(edgesGeometries, false);
  this.mergedEdgesMesh = new THREE.LineSegments(mergedGeometry, SharedMaterials.edges);
  this.scene.add(this.mergedEdgesMesh);

  // 清理临时几何体
  edgesGeometries.forEach(geom => geom.dispose());
}
```

### 6.3 交互效果适配

**悬停缩放**：通过修改 InstancedMesh 的变换矩阵实现

```javascript
_updateOuterShellScale(barIndex, scaleX, scaleZ) {
  this.tempPosition.set(bar.position.x, bar.position.y + this.maxHeight / 2, bar.position.z);
  this.tempScale.set(scaleX, 1, scaleZ);
  this.tempMatrix.compose(this.tempPosition, this.tempQuaternion, this.tempScale);
  this.outerShellInstancedMesh.setMatrixAt(barIndex, this.tempMatrix);
  this.outerShellInstancedMesh.instanceMatrix.needsUpdate = true;
}
```

**内层闪烁**：改用缩放动画代替材质变化

```javascript
_startLayerBlink() {
  this.blinkInterval = setInterval(() => {
    this.blinkState = !this.blinkState;

    instancedMesh.getMatrixAt(instanceId, tempMatrix);
    tempMatrix.decompose(tempPosition, tempQuaternion, tempScale);

    // 缩放实现闪烁效果
    tempScale.x = this.blinkState ? 1.15 : 1;
    tempScale.z = this.blinkState ? 1.15 : 1;

    tempMatrix.compose(tempPosition, tempQuaternion, tempScale);
    instancedMesh.setMatrixAt(instanceId, tempMatrix);
    instancedMesh.instanceMatrix.needsUpdate = true;
  }, 200);
}
```

## 八、后期可能存在的问题

### 8.1 边框更新性能

**问题**：边框采用几何体合并方案，每次数据更新都需要重新合并所有 8000 个边框几何体。

**影响**：频繁的数据更新可能导致卡顿。

**解决方案**：
1. 考虑使用 WebGL 着色器实现边框效果
2. 使用 `LineSegments` 的 `InstancedBufferGeometry` 方案
3. 限制边框更新频率（节流/防抖）

### 8.2 内存泄漏风险

**问题**：几何体缓存和共享材质需要正确清理。

**注意事项**：
```javascript
// 组件卸载时必须调用
GeometryCache.dispose();
SharedMaterials.outerShell.dispose();
SharedMaterials.innerLayer.dispose();
SharedMaterials.edges.dispose();
```

### 8.3 动态增删柱状图

**问题**：当前 InstancedMesh 的 count 在创建时固定，无法动态增加。

**解决方案**：
1. 预分配足够的 count，使用 visible 属性控制显示
2. 需要增加时重新创建 InstancedMesh
3. 考虑使用对象池模式

### 8.4 不同层数的柱状图

**问题**：当前所有柱状图使用相同的层基础高度，如果不同柱状图层数差异大，可能导致视觉不一致。

**解决方案**：
1. 按层数分组创建多个 InstancedMesh
2. 使用 `InstancedBufferGeometry` 支持不同尺寸

### 8.5 射线检测精度

**问题**：InstancedMesh 的射线检测基于包围球，在密集场景中可能存在误检。

**解决方案**：
1. 确保每次矩阵更新后调用 `computeBoundingSphere()`
2. 考虑实现自定义射线检测逻辑

### 8.6 材质个性化

**问题**：共享材质后，无法为单个实例设置不同颜色。

**解决方案**：
1. 使用 `InstancedMesh.setColorAt()` 设置实例颜色
2. 自定义着色器支持更多属性
