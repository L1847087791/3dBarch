# 3D 柱状图初始化逻辑优化方案

## 一、业务需求概述

根据后端返回值动态控制柱状图的属性：

| 属性 | 含义 | 种类数量 | 备注 |
|------|------|----------|------|
| 高度 | 数据值 | 连续值 | 通过 scaleY 变换 |
| 层数 | 分层数量 | 可变 | 创建时配置 |
| 外层颜色 | 系统状态 | 5-6 种 | 独立于内层 |
| 内层颜色 | 告警级别 | 4-6 种（白/蓝/黄/红...） | 与贴图独立 |
| 内层贴图 | 服务器类型 | 最多 10 种 | 只贴一个侧面 |

**关键约束**：
- 颜色和贴图相互独立，任意组合
- 采用快照模式：用户手动刷新触发重建，无需运行时动态更新

---

## 二、高度变化方案

### 2.1 方案描述

通过 `scaleY` 变换实现高度变化，所有层共享同一个几何体。

### 2.2 实现原理

```javascript
// 创建时：统一的基础高度几何体
const layerGeometry = GeometryCache.getInnerLayerGeometry(innerWidth, layerBaseHeight);

// 更新时：通过矩阵变换修改高度
this.tempScale.set(1, layerData.scaleY, 1);
this.tempMatrix.compose(this.tempPosition, this.tempQuaternion, this.tempScale);
this.innerLayerInstancedMesh.setMatrixAt(instanceId, this.tempMatrix);
```

### 2.3 架构影响

**零改动** - 当前架构已完美支持此功能。

## 三、颜色变化方案

### 3.1 方案描述

使用 Three.js 原生的 `setColorAt()` API 为每个实例设置独立颜色。

### 3.2 实现步骤

#### 步骤 1：修改材质配置

```javascript
// 启用顶点颜色
const innerLayerMaterial = new THREE.MeshPhongMaterial({
  color: 0xffffff,  // 基础色设为白色，由实例颜色覆盖
  vertexColors: true,  // 关键：启用顶点颜色
  emissive: 0xaaaaaa,
  emissiveIntensity: 0.3,
  shininess: 50
});
```

#### 步骤 2：设置实例颜色

```javascript
// 创建颜色映射表
const AlertColors = {
  normal: new THREE.Color('#ffffff'),   // 白色 - 正常
  info: new THREE.Color('#4a90d9'),     // 蓝色 - 提示
  warning: new THREE.Color('#f5a623'),  // 黄色 - 警告
  critical: new THREE.Color('#d0021b')  // 红色 - 严重
};

// 为每个实例设置颜色
function setLayerColor(instanceId, alertLevel) {
  const color = AlertColors[alertLevel] || AlertColors.normal;
  this.innerLayerInstancedMesh.setColorAt(instanceId, color);
  this.innerLayerInstancedMesh.instanceColor.needsUpdate = true;
}
```

#### 步骤 3：批量初始化

```javascript
// 创建 InstancedMesh 时初始化所有实例颜色
createBars(positions, colorData) {
  // ... 创建 InstancedMesh

  // 根据后端数据设置颜色
  colorData.forEach((barColors, barIndex) => {
    barColors.forEach((alertLevel, layerIndex) => {
      const instanceId = this.getInstanceId(barIndex, layerIndex);
      this.setLayerColor(instanceId, alertLevel);
    });
  });
}
```

### 3.3 架构影响

| 改动点 | 改动内容 | 复杂度 |
|--------|----------|--------|
| SharedMaterials | 添加 `vertexColors: true` | ⭐ 简单 |
| BarCollectionManager | 添加 `setLayerColor()` 方法 | ⭐ 简单 |
| createBars | 接收颜色数据参数 | ⭐ 简单 |

**总体评估**：改动量小，风险低。

## 四、贴图变化方案

### 4.1 方案概述

使用 **纹理图集（Texture Atlas）** + **InstancedBufferAttribute** + **自定义着色器** 实现。

核心思路：
- 将 10 种贴图合并成一张大图（纹理图集）
- 每个实例存储一个贴图索引属性
- 着色器根据索引计算 UV 坐标，采样对应区域

### 4.2 纹理图集制作

```
┌─────┬─────┬─────┬─────┬─────┐
│ T0  │ T1  │ T2  │ T3  │ T4  │  ← 第一行
├─────┼─────┼─────┼─────┼─────┤
│ T5  │ T6  │ T7  │ T8  │ T9  │  ← 第二行
└─────┴─────┴─────┴─────┴─────┘
        5 列 × 2 行 网格

每个贴图的 UV 范围计算：
- T0: u ∈ [0.0, 0.2], v ∈ [0.5, 1.0]
- T1: u ∈ [0.2, 0.4], v ∈ [0.5, 1.0]
- T5: u ∈ [0.0, 0.2], v ∈ [0.0, 0.5]
...
```

### 4.3 添加实例属性

```javascript
// 创建贴图索引属性
const textureIndices = new Float32Array(totalLayerCount);

// 根据后端数据设置每个实例的贴图索引
textureData.forEach((barTextures, barIndex) => {
  barTextures.forEach((textureIndex, layerIndex) => {
    const instanceId = this.getInstanceId(barIndex, layerIndex);
    textureIndices[instanceId] = textureIndex; // 0-9
  });
});

// 添加到几何体
layerGeometry.setAttribute(
  'aTextureIndex',
  new THREE.InstancedBufferAttribute(textureIndices, 1)
);
```

### 4.4 自定义着色器实现

#### 顶点着色器

```glsl
// 实例属性
attribute float aTextureIndex;

// 传递给片元着色器
varying float vTextureIndex;
varying vec2 vUv;
varying vec3 vNormal;

void main() {
  vTextureIndex = aTextureIndex;
  vUv = uv;
  vNormal = normalMatrix * normal;

  gl_Position = projectionMatrix * modelViewMatrix * instanceMatrix * vec4(position, 1.0);
}
```

#### 片元着色器

```glsl
uniform sampler2D uTextureAtlas;
uniform vec3 uAmbientColor;
uniform vec3 uDirectionalColor;
uniform vec3 uDirectionalVector;

varying float vTextureIndex;
varying vec2 vUv;
varying vec3 vNormal;

void main() {
  // ========== 纹理图集采样 ==========
  float cols = 5.0;
  float rows = 2.0;
  float col = mod(vTextureIndex, cols);
  float row = floor(vTextureIndex / cols);

  // 计算图集中的 UV 坐标
  vec2 atlasUV = vec2(
    (col + vUv.x) / cols,
    1.0 - (row + 1.0 - vUv.y) / rows  // Y 轴翻转
  );

  vec4 texColor = texture2D(uTextureAtlas, atlasUV);

  // ========== 单面贴图判断 ==========
  // 只在特定侧面显示贴图（例如：法线朝向 +X 的面）
  float isSideFace = step(0.9, abs(vNormal.x));

  // ========== 简化光照 ==========
  float directionalIntensity = max(dot(vNormal, uDirectionalVector), 0.0);
  vec3 lighting = uAmbientColor + uDirectionalColor * directionalIntensity;

  // ========== 最终颜色 ==========
  // 侧面使用贴图，其他面使用实例颜色
  vec3 baseColor = mix(vColor, texColor.rgb, isSideFace * texColor.a);
  gl_FragColor = vec4(baseColor * lighting, 1.0);
}
```

### 4.5 架构影响

| 改动点 | 改动内容 | 复杂度 |
|--------|----------|--------|
| 新增纹理图集 | 制作 10 合 1 贴图 | ⭐⭐ 中等 |
| SharedMaterials | 替换为 ShaderMaterial | ⭐⭐⭐ 较高 |
| 几何体 | 添加 InstancedBufferAttribute | ⭐⭐ 中等 |
| 着色器 | 编写顶点/片元着色器 | ⭐⭐⭐ 较高 |

## 五、替代方案：onBeforeCompile

### 5.1 方案描述

使用 `material.onBeforeCompile()` 注入自定义代码到现有 MeshPhongMaterial，**保留原有光照模型**，只添加贴图索引逻辑。

### 5.2 优势

- 不需要从头编写光照模型
- 复杂度降低约 50%
- 与现有材质系统兼容性更好

### 5.3 实现方式

```javascript
const innerLayerMaterial = new THREE.MeshPhongMaterial({
  color: 0xffffff,
  vertexColors: true,
  emissive: 0xaaaaaa,
  emissiveIntensity: 0.3,
  shininess: 50
});

// 注入自定义着色器代码
innerLayerMaterial.onBeforeCompile = (shader) => {
  // 添加 uniform
  shader.uniforms.uTextureAtlas = { value: textureAtlas };
  shader.uniforms.uAtlasCols = { value: 5.0 };
  shader.uniforms.uAtlasRows = { value: 2.0 };

  // 修改顶点着色器：添加属性和 varying
  shader.vertexShader = shader.vertexShader.replace(
    '#include <common>',
    `
    #include <common>
    attribute float aTextureIndex;
    varying float vTextureIndex;
    varying vec3 vWorldNormal;
    `
  );

  shader.vertexShader = shader.vertexShader.replace(
    '#include <begin_vertex>',
    `
    #include <begin_vertex>
    vTextureIndex = aTextureIndex;
    vWorldNormal = normalize(normalMatrix * normal);
    `
  );

  // 修改片元着色器：添加贴图采样
  shader.fragmentShader = shader.fragmentShader.replace(
    '#include <common>',
    `
    #include <common>
    uniform sampler2D uTextureAtlas;
    uniform float uAtlasCols;
    uniform float uAtlasRows;
    varying float vTextureIndex;
    varying vec3 vWorldNormal;
    `
  );

  // 在颜色计算后混合贴图
  shader.fragmentShader = shader.fragmentShader.replace(
    '#include <dithering_fragment>',
    `
    // 计算图集 UV
    float col = mod(vTextureIndex, uAtlasCols);
    float row = floor(vTextureIndex / uAtlasCols);
    vec2 atlasUV = vec2(
      (col + vUv.x) / uAtlasCols,
      1.0 - (row + 1.0 - vUv.y) / uAtlasRows
    );

    // 单面贴图判断（X 轴正方向侧面）
    float isSideFace = step(0.9, vWorldNormal.x);

    // 采样并混合
    vec4 texColor = texture2D(uTextureAtlas, atlasUV);
    gl_FragColor.rgb = mix(gl_FragColor.rgb, texColor.rgb, isSideFace * texColor.a);

    #include <dithering_fragment>
    `
  );
};
```

### 5.4 能否满足自定义贴图功能？

**完全可以**。`onBeforeCompile` 允许：

| 能力 | 支持情况 |
|------|----------|
| 注入自定义 uniform（纹理图集） | ✅ 支持 |
| 注入自定义 attribute（贴图索引） | ✅ 支持 |
| 修改顶点着色器 | ✅ 支持 |
| 修改片元着色器 | ✅ 支持 |
| 保留原有 Phong 光照 | ✅ 自动保留 |
| 单面贴图逻辑 | ✅ 可实现 |

### 5.5 与完全自定义着色器对比

| 对比项 | 完全自定义 ShaderMaterial | onBeforeCompile |
|--------|---------------------------|-----------------|
| 光照模型 | 需要手写 | 自动继承 Phong |
| 代码量 | 较多（~100行） | 较少（~50行） |
| 维护成本 | 较高 | 较低 |
| 灵活性 | 最高 | 高 |
| 调试难度 | 较高 | 中等 |

**推荐使用 onBeforeCompile 方案**。

## 六、实施计划

### 阶段一：颜色功能

1. 修改 `SharedMaterials.innerLayer`，添加 `vertexColors: true`
2. 在 `BarCollectionManager` 添加 `setLayerColor()` 方法
3. 修改 `createBars()` 接口，接收颜色数据
4. 测试验证

### 阶段二：贴图功能

1. 制作纹理图集（10 种贴图合并）
2. 创建 `InstancedBufferAttribute` 存储贴图索引
3. 使用 `onBeforeCompile` 注入自定义着色器代码
4. 实现单面贴图逻辑
5. 修改 `createBars()` 接口，接收贴图数据
6. 测试验证

### 阶段三：外层颜色（可选）

外层 InstancedMesh 同样可使用 `setColorAt()` 实现多颜色支持。
