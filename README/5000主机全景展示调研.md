# 5000 主机全景展示调研报告

## 一、调研结论

**✅ 完全可行**，5000 主机 + 50,000 内层实例渲染流畅，帧率稳定。

---

## 二、场景规模

| 项目 | 数量 | 实现方式 |
|------|------|----------|
| 主机（外壳） | 5,000 | 1 个 InstancedMesh |
| 内层（每主机 10 层） | 50,000 | 1 个 InstancedMesh |
| 分区 | 20 | 边框 Mesh + CSS2D 标签 |
| 分区布局 | 4 列 × 5 行 | 每区 25×10 = 250 主机 |
| **总 Draw Call** | **约 4-5 个** | 性能优秀 |

---

## 三、关键配置

```javascript
// 场景配置（BarChartContainer.jsx）
const SCENE_CONFIG = {
  hostsPerRegion: 250,    // 每区主机数
  regionCols: 25,         // 每区列数
  regionRows: 10,         // 每区行数
  layersPerHost: 10,      // 每主机内层数
  hostSpacing: 12,        // 主机间距
  totalRegions: 20,       // 总分区数
  regionsPerRow: 4,       // 每行分区数
  regionGap: 300,         // 分区间隔
};

// 相机配置（ThreeScene.js）
camera.far = 5000;                      // 远裁剪面
camera.position.set(0, 150, 350);       // 初始位置（近距离，1-2个区域）
```

## 四、实现要点

### 4.1 区域边框
- 使用 `PlaneGeometry` + `EdgesGeometry` 创建
- 边框完整包裹区域内所有主机（含边距）

### 4.2 区域标签（CSS2DRenderer）
- 使用 CSS2DObject 渲染 DOM 元素
- 文字清晰，不受距离影响
- 样式灵活，支持背景、圆角等

### 4.3 相机控制
- 初始近距离查看 1-2 个区域
- 用户滚轮拉远可查看全景
- 远裁剪面设为 5000，确保全景可见
