# Three.js 射线追踪交互指南

## 一、基本原理

射线追踪（Raycasting）是 3D 场景中实现鼠标交互的核心技术。

**工作流程**：
```
鼠标屏幕坐标 → 标准化设备坐标(NDC) → 发射射线 → 检测相交对象 → 返回交点信息
```

**核心概念**：
- **NDC 坐标**：将屏幕坐标转换为 [-1, 1] 范围，原点在视口中心
- **射线方向**：从相机位置出发，穿过 NDC 坐标点，射向场景深处
- **相交检测**：计算射线与场景中物体的几何相交

---

## 二、基本用法

### 2.1 初始化

```javascript
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();
```

### 2.2 坐标转换

```javascript
function onMouseMove(event) {
  // 屏幕坐标 → NDC 坐标
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;
}
```

### 2.3 射线检测

```javascript
// 从相机发射射线
raycaster.setFromCamera(mouse, camera);

// 检测与场景对象的相交
const intersects = raycaster.intersectObjects(scene.children, true);

if (intersects.length > 0) {
  const firstHit = intersects[0];
  console.log('命中对象:', firstHit.object);
  console.log('交点坐标:', firstHit.point);
  console.log('距离:', firstHit.distance);
}
```

## 三、InstancedMesh 射线检测

### 3.1 特殊性

`InstancedMesh` 将多个相同几何体合并为单次绘制调用，射线检测时需要识别具体是哪个实例。

**关键属性**：`intersects[0].instanceId` —— 返回被命中的实例索引

### 3.2 检测方法

```javascript
const instancedMesh = new THREE.InstancedMesh(geometry, material, count);

// 射线检测
const intersects = raycaster.intersectObject(instancedMesh);

if (intersects.length > 0) {
  const instanceId = intersects[0].instanceId;  // 实例索引
  console.log('命中实例:', instanceId);
}
```

### 3.3 实例数据映射

由于 `instanceId` 只是索引，需要建立映射关系获取业务数据：

```javascript
// 创建时建立映射
const instanceIdToData = new Map();
bars.forEach((bar, index) => {
  instanceIdToData.set(index, {
    barIndex: index,
    groupName: bar.groupName,
    uuid: bar.uuid
  });
});

// 检测时查询
const data = instanceIdToData.get(instanceId);
```

## 四、当前项目实现

### 4.1 架构概览

```
InteractionManager
├── raycaster: THREE.Raycaster
├── mouse: THREE.Vector2
├── barCollectionManager: 柱状图数据源
│
├── 外层检测: intersectObject(outerShellInstancedMesh)
└── 内层检测: intersectObject(innerLayerInstancedMesh)
```

### 4.2 检测流程

**外层悬停**：
```
mousemove → 更新 mouse 坐标 → 射线检测外壳 InstancedMesh
         → 获取 instanceId (即 barIndex)
         → 触发悬停效果
```

**内层检测**（仅在选中柱状图后）：
```
mousemove → 射线检测内层 InstancedMesh
         → 获取 instanceId
         → 通过 instanceIdToLayer 映射获取 {barIndex, layerIndex}
         → 验证是否属于当前选中柱状图
         → 触发内层闪烁
```

### 4.3 交互控制

通过 `userData.raycastEnabled` 控制是否响应射线：

```javascript
// 禁用某柱状图的射线检测
bar.outerShell.userData.raycastEnabled = false;

// 检测时判断
if (bar.outerShell.userData.raycastEnabled !== false) {
  // 处理交互
}
```

## 五、触发外部事件

### 5.1 回调机制设计

将内部事件暴露给外部组件：

```javascript
class InteractionManager {
  constructor(camera, domElement, barManager, callbacks = {}) {
    this.callbacks = {
      onBarHover: callbacks.onBarHover || null,
      onBarLeave: callbacks.onBarLeave || null,
      onBarClick: callbacks.onBarClick || null,
      onLayerHover: callbacks.onLayerHover || null,
      onLayerClick: callbacks.onLayerClick || null,
    };
  }
}
```

### 5.2 事件触发点

| 事件 | 触发时机 | 回调参数 |
|------|----------|----------|
| `onBarHover` | 鼠标移入柱状图 | `{ barIndex, bar, screenPosition }` |
| `onBarLeave` | 鼠标移出柱状图 | 无 |
| `onBarClick` | 点击柱状图 | `{ barIndex, bar, screenPosition }` |
| `onLayerHover` | 悬停内层 | `{ barIndex, layerIndex, layer }` |
| `onLayerClick` | 点击内层 | `{ barIndex, layerIndex, layer }` |

### 5.3 屏幕坐标转换

将 3D 坐标转换为屏幕坐标，用于定位 DOM 浮层：

```javascript
getScreenPosition(position3D) {
  const vector = new THREE.Vector3(position3D.x, position3D.y, position3D.z);
  vector.project(this.camera);
  const rect = this.domElement.getBoundingClientRect();
  return {
    x: (vector.x * 0.5 + 0.5) * rect.width,
    y: (-vector.y * 0.5 + 0.5) * rect.height
  };
}
```

### 5.4 React 组件集成

```jsx
// BarChart3D.jsx
<InteractionManager
  callbacks={{
    onBarClick: ({ bar, screenPosition }) => {
      props.onBarClick?.({ bar, screenPosition });
    },
    onBarHover: ({ bar, screenPosition }) => {
      props.onBarHover?.({ bar, screenPosition });
    }
  }}
/>

// 父组件
<BarChart3D
  onBarClick={({ bar, screenPosition }) => {
    setModal({ visible: true, data: bar });
  }}
  onBarHover={({ bar, screenPosition }) => {
    setTooltip({ visible: true, x: screenPosition.x, y: screenPosition.y });
  }}
/>
```

## 六、性能优化建议

| 优化项 | 方法 |
|--------|------|
| 减少检测频率 | 使用 `throttle` 限制 mousemove 触发频率 |
| 缩小检测范围 | 设置 `raycaster.far` 限制最大检测距离 |
| 分层检测 | 先检测外层，选中后再检测内层 |
| 跳过不可见对象 | 检查 `object.visible` 属性 |
