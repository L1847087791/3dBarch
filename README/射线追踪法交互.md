# 射线追踪法交互系统

## 概述

本文档详细说明 3D 柱状图项目中基于射线追踪法（Raycaster）实现的交互系统。该系统支持柱状图的外层悬停、点击选中，以及内层的悬停闪烁和点击交互。

---

## 技术原理

### 射线追踪法（Raycasting）

射线追踪是 3D 图形学中常用的物体拾取技术。其原理是：

1. 从相机位置发射一条射线，穿过鼠标在屏幕上的位置
2. 计算该射线与场景中物体的交点
3. 返回所有相交的物体（按距离排序）

```
        相机
          \
           \  射线
            \
             \
    ┌─────────●─────────┐
    │    3D 物体        │
    └───────────────────┘
```

### Three.js Raycaster

Three.js 提供了 `THREE.Raycaster` 类来实现射线追踪：

```javascript
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();

// 设置射线
raycaster.setFromCamera(mouse, camera);

// 检测相交
const intersects = raycaster.intersectObjects(objects);
```

## 核心问题与解决方案

### 问题：外层遮挡内层

柱状图由透明外壳（outerShell）和多层内部实体（innerLayers）组成。由于外壳包裹着内层，射线追踪会优先命中外壳，导致无法直接拾取内层。

### 解决方案：动态控制射线检测

通过 `userData.raycastEnabled` 属性动态控制物体是否参与射线检测：

1. **初始状态**：所有外壳可拾取
2. **选中柱状图**：禁用该柱状图外壳的射线检测，使射线可以穿透到内层
3. **切换/取消选中**：恢复外壳的射线检测

```javascript
// 禁用外层射线检测
bar.outerShell.userData.raycastEnabled = false;

// 获取可拾取的外壳时过滤
const outerShells = bars.filter(bar =>
  bar.outerShell.userData.raycastEnabled !== false
);
```

### 文件结构

### InteractionManager 类

#### 构造函数

```javascript
constructor(camera, domElement, barCollectionManager) {
  this.camera = camera;
  this.domElement = domElement;
  this.barCollectionManager = barCollectionManager;

  // 射线追踪器
  this.raycaster = new THREE.Raycaster();
  this.mouse = new THREE.Vector2();

  // 状态管理
  this.selectedBarIndex = null;    // 选中的柱状图索引
  this.hoveredBarIndex = null;     // 悬停的柱状图索引（外层）
  this.hoveredLayerIndex = null;   // 悬停的内层索引

  // 悬停缩放比例
  this.hoverScale = 1.1;

  // 内层闪烁动画
  this.blinkInterval = null;
  this.blinkState = false;
}
```

#### 鼠标坐标归一化

将屏幕坐标转换为归一化设备坐标（NDC），范围 [-1, 1]：

```javascript
_updateMousePosition(event) {
  const rect = this.domElement.getBoundingClientRect();
  this.mouse.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
  this.mouse.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;
}
```

#### 事件处理流程

```
鼠标移动 (mousemove)
    │
    ├─ 有选中的柱状图？
    │   ├─ 是 → 检测内层悬停 → 闪烁效果
    │   └─ 否 → 检测外层悬停 → 缩放效果
    │
鼠标点击 (click)
    │
    ├─ 有选中的柱状图？
    │   ├─ 是 → 检测内层点击 / 其他柱状图点击 / 空白区域
    │   └─ 否 → 检测外层点击 → 选中柱状图
```

## 功能详解

### 1. 外层悬停效果

当鼠标悬停在柱状图外壳上时，该柱状图在 X、Z 方向放大 1.1 倍。

```javascript
_applyHoverState(barIndex) {
  const bar = this.barCollectionManager.getBars()[barIndex];

  // 缩放外壳
  bar.outerShell.scale.x = this.hoverScale;
  bar.outerShell.scale.z = this.hoverScale;

  // 缩放内层（保持同步）
  bar.innerLayers.forEach(layerObj => {
    layerObj.mesh.scale.x = this.hoverScale;
    layerObj.mesh.scale.z = this.hoverScale;
    layerObj.edges.scale.x = this.hoverScale;
    layerObj.edges.scale.z = this.hoverScale;
  });
}
```

**效果**：
- 鼠标进入：柱状图放大
- 鼠标离开：柱状图恢复原大小
- 鼠标样式：悬停时变为 `pointer`

### 2. 外层点击选中

点击柱状图外壳后，进入内层交互模式。

```javascript
_onBarSelected(barIndex) {
  // 恢复之前选中柱状图的外层可拾取状态
  if (this.selectedBarIndex !== null) {
    this._restoreOuterShellRaycast(this.selectedBarIndex);
  }

  // 设置新的选中状态
  this.selectedBarIndex = barIndex;

  // 禁用当前柱状图外层的射线检测
  this._disableOuterShellRaycast(barIndex);
}
```

**控制台输出**：
```javascript
{
  barIndex: 15,
  groupName: '数据集 A',
  mesh: Mesh { ... },
  bar: BarManager { ... }
}
```

### 3. 内层悬停闪烁

选中柱状图后，悬停到内层时触发闪烁效果。

```javascript
_startLayerBlink() {
  const layerObj = bar.innerLayers[this.hoveredLayerIndex];

  // 保存原始颜色
  layerObj.mesh.userData.originalEmissive = layerObj.mesh.material.emissive.getHex();
  layerObj.mesh.userData.originalEmissiveIntensity = layerObj.mesh.material.emissiveIntensity;

  // 开始闪烁动画（200ms 间隔）
  this.blinkInterval = setInterval(() => {
    this.blinkState = !this.blinkState;
    if (this.blinkState) {
      // 高亮状态：黄色
      layerObj.mesh.material.emissive.setHex(0xffff00);
      layerObj.mesh.material.emissiveIntensity = 0.8;
    } else {
      // 恢复状态
      layerObj.mesh.material.emissive.setHex(originalEmissive);
      layerObj.mesh.material.emissiveIntensity = originalIntensity;
    }
  }, 200);
}
```

**效果**：
- 闪烁颜色：黄色 (`0xffff00`)
- 闪烁间隔：200ms
- 移出内层时自动停止闪烁并恢复原色

### 4. 内层点击

点击内层时，控制台输出该层的详细信息。

```javascript
console.log('点击了内层:', {
  barIndex: this.selectedBarIndex,
  layerIndex: layerIndex,
  groupName: intersected.userData.groupName,
  mesh: intersected,
  layerData: intersected.userData
});
```

**控制台输出**：
```javascript
{
  barIndex: 15,
  layerIndex: 5,
  groupName: '数据集 A',
  mesh: Mesh { ... },
  layerData: {
    type: 'innerLayer',
    layerIndex: 5,
    barIndex: 15,
    groupName: '数据集 A',
    baseHeight: 0.89
  }
}
```

### 5. 状态切换

| 操作 | 结果 |
|------|------|
| 点击柱状图 A | 选中 A，禁用 A 外层射线检测 |
| 再点击柱状图 B | 恢复 A 外层，选中 B，禁用 B 外层 |
| 点击空白区域 | 取消选中，恢复所有外层可拾取 |

## userData 数据结构

### 外壳 (outerShell)

```javascript
outerShell.userData = {
  type: 'outerShell',        // 类型标记
  barIndex: 0,               // 柱状图索引 (0-79)
  groupName: '数据集 A',      // 所属堆名称
  raycastEnabled: true       // 是否可被射线拾取
};
```

### 内层 (innerLayer)

```javascript
layerMesh.userData = {
  type: 'innerLayer',        // 类型标记
  layerIndex: 0,             // 层索引 (0 ~ layerCount-1)
  barIndex: 0,               // 所属柱状图索引
  groupName: '数据集 A',      // 所属堆名称
  baseHeight: 0.89           // 基础高度
};
```

## 扩展建议

### 1. 添加 Tooltip

在内层悬停时显示数据信息：

```javascript
_handleInnerLayerHover() {
  // ... 现有代码 ...

  if (intersects.length > 0) {
    // 显示 Tooltip
    this._showTooltip(intersected.userData);
  } else {
    // 隐藏 Tooltip
    this._hideTooltip();
  }
}
```

### 2. 添加相机动画

选中柱状图后，相机移动到该柱状图近景：

```javascript
_onBarSelected(barIndex) {
  // ... 现有代码 ...

  // 相机动画（使用 Tween.js）
  const targetPosition = this._calculateCameraTarget(barIndex);
  new TWEEN.Tween(this.camera.position)
    .to(targetPosition, 1000)
    .easing(TWEEN.Easing.Quadratic.Out)
    .start();
}
```

### 3. 多选支持

修改 `selectedBarIndex` 为数组，支持多个柱状图同时选中：

```javascript
this.selectedBarIndices = [];

_onBarSelected(barIndex) {
  if (event.ctrlKey) {
    // Ctrl + 点击：多选
    this.selectedBarIndices.push(barIndex);
  } else {
    // 单击：单选
    this.selectedBarIndices = [barIndex];
  }
}
```

## 性能考虑

1. **事件节流**：`mousemove` 事件频繁触发，可考虑使用 `requestAnimationFrame` 或 `throttle` 进行节流

2. **射线检测优化**：只检测可见且在视锥体内的物体

3. **闪烁动画**：使用 `setInterval` 实现，可考虑改用 `requestAnimationFrame` 以获得更平滑的效果
