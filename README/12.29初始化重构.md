# 12.29 初始化逻辑重构

## 一、重构目标

将柱状图的高度控制逻辑从固定 `maxHeight` 改为动态高度，支持：
- 外层高度由后端数据控制
- 内层自适应撑满外层
- 共享几何体，通过 scaleY 变换实现不同高度

---

## 二、核心改动

### 2.1 数据接口格式

```javascript
const sceneData = {
  bars: [
    {
      position: { x: 0, y: 0, z: 0 },
      groupName: '数据集 A',
      height: 40,  // 外层目标高度
      layers: [{}, {}, ...]  // 数组长度决定层数
    }
  ]
};

// 调用方式
barCollectionManager.createBars(sceneData, barWidth, initHeight);
// barWidth: 柱状图宽度
// initHeight: 初始高度（用于共享几何体）
```

### 2.2 高度计算逻辑

```
几何体创建：基于 initHeight
外壳 scaleY = bar.height / initHeight
内层 scaleY = (实际层高) / (基准层高)
内层位置 = 根据实际高度重新计算
```

```javascript

 * 更新外层高度，内层自适应撑满

```

### BarCollectionManager

```javascript
/**
 * 更新外壳实例的矩阵（支持高度缩放）

_updateOuterShellMatrix(barIndex, scaleY)
```

## 五、使用示例

```javascript
// 1. 生成场景数据
const sceneData = {
  bars: [
    { position: {x:0, y:0, z:0}, groupName: 'A', height: 40, layers: Array(50).fill({}) },
    { position: {x:20, y:0, z:0}, groupName: 'A', height: 35, layers: Array(50).fill({}) },
  ]
};

// 2. 创建柱状图（initHeight=5 用于共享几何体）
barCollectionManager.createBars(sceneData, 8, 5);

// 3. 后续更新高度（可选）
barCollectionManager.updateAllHeights([50, 45, 40, ...]);
```

## 七、Bug 修复：不同层数柱状图互相影响

### 7.1 问题现象

当某个柱状图的 `layers.length` 与其他柱状图不同（如10层 vs 50层）时：
- 柱状图位置和外观异常
- 鼠标悬停内层效果错误

### 7.2 问题根因

```javascript
// 旧代码：取第一个柱状图的层数作为全局基准
this.defaultLayerCount = barsData[0]?.layers?.length || 0;

// 几何体尺寸基于 defaultLayerCount 计算
const layerBaseHeight = availableHeight / this.defaultLayerCount;
```

导致：层数不同的柱状图使用错误的基准高度计算 `scaleY`。

### 7.3 修复方案

引入**统一的 `baseLayerHeight`**，基于固定的 `baseLayerCount=50` 计算：

```javascript
// 新代码：固定基准层数
createBars(sceneData, barWidth, initHeight, baseLayerCount = 50) {
  this.baseLayerHeight = (initHeight - gaps) / baseLayerCount;
}

// 每个柱状图独立计算 scaleY
initLayerData() {
  const actualLayerHeight = availableHeight / this.layerCount;  // 自己的层数
  const scaleY = actualLayerHeight / this.baseLayerHeight;      // 统一基准
}
```

### 7.4 改动文件

| 文件 | 改动 |
|-----|------|
| `BarManager.js` | 构造函数新增 `baseLayerHeight` 参数 |
| `BarManager.initLayerData()` | 使用统一基准计算 `scaleY` |
| `BarCollectionManager.createBars()` | 新增 `baseLayerCount` 参数 |
| `_createInnerLayerInstancedMesh()` | 使用 `this.baseLayerHeight` |
| `_createMergedEdges()` | 使用 `this.baseLayerHeight` |
