# 12.29 初始化逻辑重构

## 一、重构目标

将柱状图的高度控制逻辑从固定 `maxHeight` 改为动态高度，支持：
- 外层高度由后端数据控制
- 内层自适应撑满外层
- 共享几何体，通过 scaleY 变换实现不同高度

---

## 二、核心改动

### 2.1 数据接口格式

```javascript
const sceneData = {
  bars: [
    {
      position: { x: 0, y: 0, z: 0 },
      groupName: '数据集 A',
      height: 40,  // 外层目标高度
      layers: [{}, {}, ...]  // 数组长度决定层数
    }
  ]
};

// 调用方式
barCollectionManager.createBars(sceneData, barWidth, initHeight);
// barWidth: 柱状图宽度
// initHeight: 初始高度（用于共享几何体）
```

### 2.2 高度计算逻辑

```
几何体创建：基于 initHeight
外壳 scaleY = bar.height / initHeight
内层 scaleY = (实际层高) / (基准层高)
内层位置 = 根据实际高度重新计算
```

## 三、文件改动

### 3.1 BarChart3D.jsx

| 改动 | 说明 |
|------|------|
| `generateBarPositions()` → `generateSceneData()` | 数据格式统一化 |
| 添加 `height` 字段 | 每个 bar 的目标高度 |
| `layers` 简化 | 不再需要 `value`，只需确定层数 |

### 3.2 BarManager.js

**BarManager 类**

| 改动 | 说明 |
|------|------|
| `maxHeight` → `initHeight` | 初始高度（几何体基准） |
| 新增 `currentHeight` | 当前外层高度 |
| `updateHeight()` → `updateOuterHeight()` | 更新外层高度，内层自适应 |

**BarCollectionManager 类**

| 改动 | 说明 |
|------|------|
| `maxHeight` → `initHeight` | 参数名变更 |
| `createBars(sceneData, barWidth, initHeight)` | 接口变更 |
| 新增 `_updateOuterShellMatrix()` | 更新外壳矩阵（支持高度缩放） |
| 修改 `_initializeHeights()` | 使用 sceneData 中的 height |
| 修改 `_updateOuterShellScale()` | 保持当前高度的同时更新 X/Z 缩放 |

### 3.3 InteractionManager.js

| 改动 | 说明 |
|------|------|
| `_updateCursorPosition()` | 使用 `bar.currentHeight` 定位光标 |
| `_updateBarInstanceScale()` | 使用 `layerData.scaleY` 确保 Y 轴正确 |
| `_startLayerBlink()` | 闪烁时保持正确的 Y 缩放 |
| `_stopLayerBlink()` | 恢复时使用保存的 scaleY |

---

## 四、新增方法

### BarManager

```javascript
/**
 * 更新外层高度，内层自适应撑满
 * @param {number} newHeight - 新的外层高度
 * @returns {Object} { outerScaleY, innerLayers }
 */
updateOuterHeight(newHeight)
```

### BarCollectionManager

```javascript
/**
 * 更新外壳实例的矩阵（支持高度缩放）
 * @param {number} barIndex - 柱状图索引
 * @param {number} scaleY - Y轴缩放
 */
_updateOuterShellMatrix(barIndex, scaleY)

/**
 * 更新所有柱状图的高度
 * @param {Array} heights - 每个柱状图的目标高度数组
 */
updateAllHeights(heights)
```

---

## 五、使用示例

```javascript
// 1. 生成场景数据
const sceneData = {
  bars: [
    { position: {x:0, y:0, z:0}, groupName: 'A', height: 40, layers: Array(50).fill({}) },
    { position: {x:20, y:0, z:0}, groupName: 'A', height: 35, layers: Array(50).fill({}) },
  ]
};

// 2. 创建柱状图（initHeight=5 用于共享几何体）
barCollectionManager.createBars(sceneData, 8, 5);

// 3. 后续更新高度（可选）
barCollectionManager.updateAllHeights([50, 45, 40, ...]);
```

## 六、未完成：颜色方案

### 6.1 需求

| 属性 | 含义 | 种类 |
|------|------|------|
| 内层颜色 | 告警级别 | 4-6种（白/蓝/黄/红） |
| 内层贴图 | 服务器类型 | 最多10种（只贴侧面） |
| 外层颜色 | 系统状态 | 5-6种 |

颜色与贴图相互独立，任意组合。

### 6.2 计划方案

**颜色实现**：使用 `InstancedMesh.setColorAt()`

```javascript
// 材质启用顶点颜色
const material = new THREE.MeshPhongMaterial({
  vertexColors: true,
  // ...
});

// 设置实例颜色
instancedMesh.setColorAt(instanceId, new THREE.Color('#ff0000'));
instancedMesh.instanceColor.needsUpdate = true;
```

**贴图实现**：使用 `onBeforeCompile` 注入着色器

```javascript
material.onBeforeCompile = (shader) => {
  // 注入纹理图集和贴图索引逻辑
  // 保留原有 Phong 光照
};
```
